# Hospital Management System Analytics (SQL)

This project presents an **SQL-based analytics report for a Hospital Management System**. It analyzes hospital data using multiple relational tables to extract meaningful insights about hospital operations.

## 📊 Project Overview

The database includes several tables representing different entities of a hospital system, such as:

* **Patients**
* **Doctors**
* **Departments**
* **Appointments**
* **Medications**
* **Bills**

Using SQL queries, the project demonstrates how hospital data can be structured, managed, and analyzed to support decision-making.

## 🎯 Objectives

* Manage hospital data using structured tables
* Perform data analysis using SQL queries
* Understand relationships between hospital entities

## 🛠️ Technologies Used

* SQL
* Relational Database Management system

This project is useful for learning **database design, SQL querying, and healthcare data analytics concepts**.
